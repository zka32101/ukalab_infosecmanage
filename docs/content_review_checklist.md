# 問題コンテンツ 専門確認チェックリスト

> 全 833 問は **仮データ**(自作・正誤の専門確認が未了)。本書は専門家(情報セキュリティ分野の有識者・試験対策の実務者)による確認の **手順書** であり、確認済みを意味しない。判定欄は空欄(未確認)。

## 手順

1. 優先順(P1→P2→P3)に従い、表の問題を `assets/questions/info_security.jsonl` と見比べる。
2. 各問を次の観点で確認する: (a) 正解が事実として正しい (b) 他の3択が確実に誤り(正解が一意) (c) 解説が正解と矛盾せず事実として正しい (d) 用語・表記が試験で通用する (e) 法令・規格は現行(改正・版)に合っている (f) IPA 出題範囲の項目に対応している。
3. 判定欄に記号を記入: `OK`(修正不要) / `修正`(内容修正が必要。修正案を備考へ) / `削除`(出題に不適) / `保留`(要追加調査)。
4. 1問ごとに確認者・確認日・根拠(一次資料名と版)を備考に書く。**根拠を示せない場合は OK にしない**。
5. 判定が出た問題だけ別PRでデータ修正する(`contentVer` を更新)。公開前の判断は運営者が行う。
6. 機械検査の結果は [`docs/content_audit_report.md`](content_audit_report.md) を参照(「確認観点」の付記はその検査由来)。

- P3 通常(技術用語・一般知識)
